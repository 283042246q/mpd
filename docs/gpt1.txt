项目交接摘要：Real-Time / Space-Time MPD + CDSG + World Model
1. 当前总体研究方向

项目从原始 Motion Planning Diffusion (MPD) 出发，目标是发展成面向真实动态环境、可实时执行的规划系统。

路线经过讨论后已经逐渐从：

Global MPD + Local Planner + CDSG + 异步重规划

转向更统一的单 planner 方案：

Space-Time MPD+Timing B-spline+CDSG+未来可选 World Model
	​


当前倾向不把两级 Local/Global Planner 作为主论文结构。

因此后续 CDSG 应尽量产生 固定 shared tensor shape，避免 candidate-specific runtime masks。
