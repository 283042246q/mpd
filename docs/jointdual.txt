2. Dynamic World Encoder
这是 JD-WORLD 相比 JD-KIN 新增的第一块。
假设 obstacle \(j\) 在采样时间 \(t_r\) 的描述为：
\[
o_{j,r}
=
[
p_j(t_r),
R_j(t_r),
v_j(t_r),
g_j,
\mathrm{PE}(t_r)
].
\]
其中 \(g_j\) 是 size / radius / primitive type 等几何信息。
每个 obstacle-time instance 独立编码：
\[
w_{j,r}
=
\phi_{\rm world}(o_{j,r})
\in\mathbb R^{d_w}.
\]
例如：
\[
\phi_{\rm world}(o)
=
W_2\sigma(W_1o+b_1)+b_2.
\]
最终得到：
\[
W=
[w_1,\ldots,w_M]
\in
\mathbb R^{B\times M\times d_w}.
\]
这里：
\[
M=N_{\rm obs}N_{\rm time}.
\]
这是直接借鉴 CAMPD 的：
\[
z_{c_{k,l}}=\mathrm{MLP}_k(c_{k,l}),
\]
即每个 context instance 独立 MLP，然后作为 attention 的 K/V。arXiv

4. JD-WORLD 中 Timing branch 怎么看 dynamic world
有两个实现。
简单 V1：pool world
先：
\[
g_W
=
\frac{

其中 \(m_m\) 是 padding mask。

\[

最简单，但损失：
- obstacle identity；
- temporal location；
- obstacle-to-obstacle structure。
更推荐：single-query cross attention
让 timing latent 作为一个 query：
\[
Q_z=\bar h_zW_Q,
\]
world tokens：
\[
K_W=WW_K,
\qquad
V_W=WW_V.
\]
然后：
\[
A_z
=
\operatorname{softmax}
\left(
\frac{Q_zK_W^T}{\sqrt d}
+M
\right),
\]
\[
a_z=A_zV_W.
\]
最后 residual：
\[
h_z
=
\mathrm{LN}
(
\bar h_z+W_Oa_z
).
\]
再接 FFN：
\[
h_z
\leftarrow
\mathrm{LN}
\left[
h_z+
W_2\sigma(W_1h_z)
\right].
\]
这个其实就是标准 cross-attention，只是 Timing branch 只有一个 query token。

\[

\]

\[

6. FiLM 怎么把 Timing 信息注入 Spatial Encoder
定义 global conditioning：
\[
g=
[e_k,e_{\rm task},h_z].
\]
对于第 \(l\) 层：
\[
(\gamma_l,\beta_l)
=
W_lg+b_l.
\]
假设 residual feature：
\[
H_l\in\mathbb R^{B\times C_l\times L_l}.
\]
先 convolution / norm：
\[
U_l
=
\mathrm{GN}
(
\mathrm{Conv1D}(H_l)
).
\]
FiLM：
\[
\tilde U_l
=
(1+\gamma_l)\odot U_l+\beta_l.
\]
其中：
\[
\gamma_l,\beta_l\in\mathbb R^{B\times C_l}
\]
broadcast 到 length 维。
然后：
\[
R_l=
\mathrm{Conv1D}
(
\sigma(\tilde U_l)
).
\]
Residual：
\[
H_l'
=
S_l(H_l)+R_l,
\]
\(S_l\) 是 identity 或 \(1\times1\) projection。
再 downsample：
\[
H_{l+1}
=
D_l(H_l').
\]
所以 timing 对 spatial 的作用不是：
\[
[c,T]
\]
硬拼到每个控制点，而是：
\[
\boxed{
(c,T)
\rightarrow h_z
\rightarrow
(\gamma_l,\beta_l)
\rightarrow
\text{modulate spatial feature}
}
\]
这个更合理。

这块是整个 JointDual 真正区别于 factorized 的关键。
输入：

\quad
h_z,
\quad

\quad

\]
JD-WORLD 里 world 已经进入 \(h_z,H_P\)，所以首版没必要再 concat 一次完整 world tokens。
定义：
\[
f_0
=
[
h_P,
h_z,
e_k,
e_{\rm task}
].
\]
然后：
\[
u=W_f f_0+b_f.
\]
一个两层 Residual MLP：
\[
r
=
W_2
\sigma
(
W_1\mathrm{LN}(u)+b_1
)
+b_2,
\]
\[
\boxed{
h_{\rm joint}=u+r.
}
\]
例如：
\[
\dim h_{\rm joint}=256.
\]
这代表：
\[
h_{\rm joint}
=
F(P_k,c_k,T_k,k,task,world).

10. Timing Head 的数学实现
我会建议比 MD 里再稍微好一点：保留 timing residual path。
先：
\[
h_t
=
h_z+
W_{tj}h_{\rm joint}.
\]
然后：
\[
r_t
=
h_t+
W_{t2}
\sigma(
W_{t1}\mathrm{LN}(h_t)
).
\]
最后两个独立 heads：
\[
\boxed{
\hat\epsilon_c
=
W_c r_t+b_c
}
\]
和：
\[
\boxed{
\hat\epsilon_T
=
W_T r_t+b_T.
}
\]
输出：
\[
\hat\epsilon_c\in\mathbb R^{B\times N_c},
\]
\[
\hat\epsilon_T\in\mathbb R^{B\times1}.
\]
为什么分头？
因为：
\[

\]
控制 local timing shape，
而：
\[
T
\]
控制 global duration。
没必要强迫最后一个 linear layer 把两者当成同一种 variable。
11. Spatial Decoder 怎么算
Spatial decoder 使用：
\[
H_P
\]
以及 encoder skip features：
\[
S_1,S_2,\ldots.
\]
同时 conditioning 改为：
\[
g_{\rm dec}
=
[e_k,e_{\rm task},h_{\rm joint}].
\]
每层：
\[
H_l^{up}
=
\mathrm{Upsample}(H_l).
\]
拼 skip：
\[
\tilde H_l
=
[
H_l^{up},S_l
].
\]
再用同样 FiLM residual blocks：
\[
H_l'
=
\mathrm{ResBlock}
(
\tilde H_l;
g_{\rm dec}
).
\]
最后：
\[
\boxed{
\hat\epsilon_P
=
\mathrm{Conv1D}_{1\times1}
(H_{\rm final})
}
\]
恢复：
\[
\hat\epsilon_P
\in
\mathbb R^{B\times N_P\times d_q}.
\]
这与 MPD 当前 TemporalUnet 的 decoder 结构非常接近：encoder skip 与 decoder feature concat，然后 residual blocks + upsample，最后 Conv1D 输出原 state dimension。GitHub
